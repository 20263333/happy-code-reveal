# Навсозии CRM, WhatsApp ва шаблони чек

## Дар терминали сервер

```bash
cd /var/www/binosoz &&
git pull &&
bash scripts/apply-migrations-vps.sh &&
bash scripts/deploy-vps.sh
```

Фармони ҳамоҳангсозӣ қисми қабул ва нигоҳдории паёмҳои Wappi, инчунин майдони шаблони DOCX-и чекро илова мекунад. Мизоҷон ва пардохтҳои пешина тоза намешаванд.

## Дар Wappi

Суроғаи қабули паёмҳоро аз домени лоиҳаи кӯҳна ба ин суроға иваз кунед:

```text
https://binosoz.tj/api/public/hooks/whatsapp-leads
```

Калиди мавҷудаи қабул бояд бо `WAPPI_WEBHOOK_AUTH_TOKEN`-и сервер мувофиқ бошад. Калидро дар чат ё акс нишон надиҳед. Profile ID дар танзимоти WhatsApp бояд ба ширкати дуруст пайваст бошад. Санҷиши кушодани суроға танҳо дастрасии онро нишон медиҳад, на қабули воқеии паём.

Аз рақами дигар паёми нав фиристед: мизоҷ ва матни паём бояд дар WhatsApp ва Воронкаи фурӯши ҳамон ширкат пайдо шаванд. Барои хатоҳо «Журнал»-ро бинед. Паёмҳое, ки пештар ба суроғаи кӯҳна рафтаанд, худкор аз Wappi гирифта намешаванд; дубора фиристодани онҳоро дар Wappi санҷед.

## Шартнома ва чек

- Дар «Шаблон договора» рӯйхати 22 тег ва нусхабардории ҳар тег ҷойгир аст.
- Дар «Танзимот» → «Шаблони чек / квитанция» файли DOCX-и чекро бор кунед.
- Дар файли нави чек `{{amount}}` ва `{{amount_words}}` маблағи ҳамин пардохтанд; `{{total_price}}` арзиши умумии хона аст.
- Чеки пешфарз барои мувофиқат бо шаблони пешина `{{total_price}}`-ро ҳамчун маблағи ҳамин пардохт нигоҳ медорад.
- Шаблони чек ба «Чек DOCX» дар пардохтҳо истифода мешавад; чопи оддӣ/PDF шакли ҷудогона дорад.

## Санҷиши анҷомшуда

Дар ҳисоби муваққатии санҷишӣ ду паёми намунавӣ ба қабулкунанда фиристода шуданд; ҳар ду мизоҷ ва матни паём дар CRM пайдо шуданд. DOCX-и чек боргузорӣ шуда, баъди нав кардани саҳифа нигоҳ дошт ва чек бо 3 ҳуҷра, 80 м², арзиши 880000 сомонӣ ва пардохти алоҳидаи 5000 сомонӣ зеркашӣ шуд. Сабтҳои санҷишӣ баъди санҷиш тоза мешаванд. Навсозӣ ва қабули паёми воқеӣ аз Wappi дар VPS ҳанӯз аз ҷониби соҳиби сервер иҷро мешаванд.
