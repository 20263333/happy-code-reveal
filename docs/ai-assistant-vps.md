# Ёрдамчии AI-и ширкат

Ёрдамчӣ маълумоти қисматҳои ширкатро мехонад ва ҳисоботи давраи интихобшударо медиҳад. Барои даромади моҳона пардохтҳои тасдиқшуда ҳисоб мешаванд; асъорҳо алоҳидаанд. Хароҷот ва бақия низ нишон дода мешаванд.

Мисолҳои дархост:
- «Даромади ширкати ман дар моҳи ноябр чанд буд?»
- «Дар блоки А рақами хонаи 12-ро ба 15 иваз кун».
- «Масоҳати хонаи 15-ро 65 м² гузор, нархи умумиро нигоҳ дор».
- «Телефони муштарии Фаридро иваз кун».

Пеш аз сабти тағйирот пешниҳод бо маълумоти пешина ва нав пайдо мешавад. Тугмаи **Тасдиқи тағйирот** онро сабт мекунад; **Бекор кардани тағйирот** маълумотро бетағйир мемонад. Пешниҳод 30 дақиқа эътибор дорад. Агар маълумот дар ҳамин вақт тағйир ёбад, дархости нав лозим аст.

Дастрасӣ танҳо ба ширкати соҳиби воридшуда аст. Паролҳо, калидҳои API, таъини ҳуқуқҳо, тарифҳо ва маълумоти ширкатҳои дигар дастрас нестанд. Ҳамаи қисматҳо иҷозати таҳрири ҳамаи майдонҳоро надоранд: маблағҳои ҳисобшуда ва амалҳои махсус бо қоидаҳои худ муҳофизат мешаванд. Тағйири масоҳати хона шартномаҳои пешинаро тағйир намедиҳад.

## Навсозӣ дар сервер

```bash
cd /var/www/binosoz &&
git pull &&
bash scripts/apply-migrations-vps.sh &&
bash scripts/deploy-vps.sh
```

Сипас сайтро аз нав кушоед. Калиди мавҷудаи OpenAI-и сервер нигоҳ дошта мешавад; онро ба код ё чат нагузоред. Ин навсозӣ дар сервер аз ин муҳит иҷро нашудааст.

## Хатои 429

429 метавонад аз маҳдудияти муваққатии дархостҳо ё маблағ/лимити пардохти ҳисоби AI бошад. Барнома онҳоро аз рӯйи коди ҷавоби хизматрасонӣ фарқ мекунад; ҷавоби номуайян ҳамчун сабаби дақиқ нишон дода намешавад. Ҳангоми рад шудани AI дархости барнома худкор такрор намешавад ва матни паёми ёрдамчӣ нигоҳ дошта мешавад.

Пас аз навсозӣ модели воқеии ёрдамчии серверро санҷед:

```bash
cd /var/www/binosoz && bash scripts/check-ai-vps.sh chat
```

Фармон як дархости хурди санҷишӣ мефиристад ва метавонад хароҷоти ками AI дошта бошад. Он калид ва ҷавоби пурраи хизматрасониро нишон намедиҳад. Агар сабаб маблағ бошад, маблағ/лимити ҳисоби OpenAI ё хизматрасонии интихобшударо барқарор кунед: обунаи ChatGPT ва кредитҳои Binosoz.tj аз он алоҳидаанд. Иваз кардани калид, барнома ё модели AI ин маҳдудиятро худкор бартараф намекунад.

### Ҷойҳои санҷидашуда

- Ёрдамчӣ ва воридкунии овозӣ: паёми умумии HTTP иваз шуд; матни ноком нигоҳ дошта мешавад.
- Паспорт дар ширкат ва киоск, инчунин сохтордиҳии матни паспорт: хатои маблағ/429 дигар ҳамчун акси норавшан нишон дода намешавад ва такрори худкори 429 қатъ мешавад.
- Чек/патент ва накладнойи склад: радшавии хизматрасонӣ дигар модели навбатӣ ё кӯшиши худкори аксро фаъол намекунад.
- Сканери шартнома ва шинохти рӯй дар табелу киоск: ҳамон шарҳи бехатари сабаб истифода мешавад; ҳуқуқ ва сабти табел бетағйир мемонанд.
- Проксии AI: коди HTTP ва ҷавоби хизматрасониро аллакай мегузаронад, такрор надорад; истеъмолкунандагон сабабро мехонанд.
- Кредитҳои барнома ва тасдиқи тағйироти AI: дархости модели AI надоранд; қоидаҳо, бақияҳо ва амалҳои анҷомшуда тағйир дода нашуданд.
- Равандҳои сервер: дар ҷойҳои ҷустуҷӯшуда кори заминавии AI ё функсияи базаи даъваткунандаи AI ёфт нашуд; санҷиши дастии VPS нав шуд.
