# Ҷудокунии пурраи маълумоти ширкатҳо

## Натиҷа
Ҳар соҳиби ширкат ва кормандони ӯ танҳо маълумоти ширкати худро мебинанд. Иваз кардани аккаунт дар ҳамон браузер дигар маълумоти ширкати пешинаро нишон намедиҳад.

## Корҳо
1. Кэши браузерро ба ID-и корбар ва ширкат вобаста карда, ҳангоми воридшавӣ/баромадан ё иваз шудани аккаунт кэши пешинаро пурра тоза мекунем.
2. Дар саҳифаҳои ҳисобот, андоз, қарздорон, муштариён, қарзҳои пардохтшаванда, кормандон ва хароҷот ба ҳамаи дархостҳо филтри ҳатмии ширкат илова мекунем.
3. Дар функсияҳои серверӣ ID-и ширкатро аз аккаунти тасдиқшуда муайян мекунем; ID-и аз браузер омада барои дастрасӣ асос намешавад.
4. Қоидаҳои базаи VPS-ро барои ҳамаи ҷадвалҳои асосӣ ва ҷадвалҳои вобаста бозбинӣ карда, муҳофизати қатъии ширкат/лоиҳа мегузорем.
5. Бо ду аккаунти ширкат санҷиш мекунем: рӯйхатҳо, лоиҳаҳо, муштариён, фурӯш, молия ва анбор набояд бо ҳам омехта шаванд.

## Тафсилоти техникӣ
- Query key ва нигоҳдории localStorage барои ҳар user/company алоҳида мешавад.
- Ҳангоми SIGNED_OUT ё SIGNED_IN бо user-и дигар query cache ва persistent cache тоза мешавад.
- Дар VPS SQL қоидаҳои маҳдудкунанда (restrictive tenant policies) ҳамчун муҳофизати иловагӣ татбиқ мешаванд.
- Пас аз санҷиш фармонҳои ягонаи навсозии VPS дода мешаванд.
