# Тарифҳо ва дархостҳои сайт

## Натиҷа
- Бахши «Имкониятҳои платформа»-ро бо ҳамаи гурӯҳҳо ва тавсифҳои пешниҳодшуда пурра мекунем: сохтмон ва фурӯш, молия, майдони сохтмон ва идоракунӣ.
- Се карточкаи тарифӣ месозем: «Сохтмон», «Сохтмон + Фурӯш» ва «Premium Unlimited»; карточкаи миёна бо нишони «Маъмул» ва намуди барҷаста мисли намуна мешавад.
- Пахши «Интихоби тариф» равзанаи дархостро мекушояд ва тарифи интихобшударо пешакӣ мегузорад.
- Равзана майдонҳои навъи бизнес, ном, ширкат, вазифа, email ва телефон дорад; санҷиши дурустии майдонҳо ва ҳолатҳои ирсол/муваффақият нишон дода мешаванд.
- Дархост бехатар сабт шуда, дар Super Admin дар бахши нави «Дархостҳои сайт» бо тариф, маълумоти тамос, сана ва ҳолат намоён мешавад.
- Super Admin метавонад дархостро «Нав», «Дар кор» ё «Анҷом шуд» кунад.

## Забон ва намоиш
- Ҳамаи матнҳои нав ба тоҷикӣ, русӣ ва англисӣ тарҷума мешаванд ва бо интихоби забони умумии сайт иваз мешаванд.
- Карточкаҳо ва равзана дар компютер ва телефон бе буридашавӣ кор мекунанд.
- Аниматсияҳои мавҷудаи пайдоиш ҳангоми ҳаракат барои бахшҳои нав нигоҳ дошта мешаванд.

## Техникӣ
- Барои дархостҳо ҷадвали алоҳида бо дастрасии оммавӣ танҳо барои сабт ва дастрасии хондан/тағйирдиҳӣ танҳо ба Super Admin сохта мешавад.
- Ирсол аз сайт тавассути вазифаи серверӣ бо санҷиши маълумот анҷом меёбад; Super Admin маълумотро тавассути иҷозатҳои мавҷуда мехонад.
- Пас аз тағйирот намуди тарифҳо, кушодану бастани равзана, ирсоли санҷишӣ, намоиши Super Admin ва се забон санҷида мешаванд.
