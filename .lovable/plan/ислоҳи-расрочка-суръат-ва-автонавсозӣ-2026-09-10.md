# Ислоҳи расрочка, суръат ва автонавсозӣ

## Натиҷа
- Карточкаи расрочка маблағ ва шумораи муштариёнро аз маълумоти воқеии ширкати воридшуда нишон медиҳад.
- Маълумоти саҳифаи кушода ҳар 5 сония нав мешавад, бе он ки тамоми барнома якбора аз нав бор шавад.
- Гузариш байни саҳифаҳо ва нишон додани маълумот тезтар мешавад.

## Корҳо
- Ислоҳ кардани муайянкунии ширкат барои ҳисобе, ки ҳам Super Admin ва ҳам соҳиби ширкат аст.
- Хондани расрочка аз тарафи сервер бо санҷиши дастрасӣ, то қоидаҳои нопурраи VPS маълумотро пинҳон накунанд.
- Маҳдуд кардани дархости расрочка ба ширкати ҷорӣ ва маълумоти зарурӣ.
- Қатъ кардани синхронизатсияи вазнини ҳар 3 сония дар дашборд.
- Гузоштани навсозии 5-сониягӣ танҳо барои маълумоти зиндаи саҳифаи кушода: дашборд, расрочка ва тақсимоти даромад.
- Илова кардани хатои равшан ва тугмаи такрор, агар маълумот бор нашавад.
- Санҷидани сохт ва кори саҳифа пас аз тағйирот.

## Қисми техникӣ
- React Query кэши мавҷударо нигоҳ медорад; refetch танҳо барои query-ҳои фаъоли лозима истифода мешавад.
- Server function бо истифодабарандаи воридшуда ширкатро муайян карда, маълумоти `payment_schedule`-ро бо scope-и ширкат бармегардонад.
- Ҳисоби Super Admin-и соҳиби ширкат ҳам `companyId` ва ҳам ҳуқуқи owner-ро нигоҳ медорад.
