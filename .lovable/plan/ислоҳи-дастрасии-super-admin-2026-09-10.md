# Ислоҳи дастрасии Super Admin

## Натиҷа
Корбари сабтшуда дар `platform_admins` фавран ҳамчун Super Admin шинохта мешавад ва дигар аз хатои ҷадвали профил вобаста намемонад.

## Тағйирот
- Санҷиши `platform_admins`-ро аз боркунии профил ва ширкати корбар ҷудо мекунем.
- Агар сабти Super Admin дуруст хонда шавад, ҳолати дастрасӣ фавран фаъол мешавад.
- Боркунии маълумоти оддии профил барои кормандон ҳамоно бо санҷиши пешина мемонад.
- Санҷиши сохт ва хатогиҳои барномаро иҷро мекунем.

## Қадами сервер
Пас аз тағйирот дар VPS: `git pull` ва `bash scripts/deploy-vps.sh`, сипас аз аккаунт баромада дубора ворид шудан.
